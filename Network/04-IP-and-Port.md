# IP 주소와 포트 (IP Address & Port)

## 개념

IP 주소는 네트워크상의 목적지를 식별하고, 포트 번호는 TCP/UDP 통신에서 해당 호스트의 소켓이나 서비스를 구분하는 데 사용된다.

```text
Client: 192.168.0.5:52341  --->  Server: 10.0.0.20:1111
Client: 192.168.0.5:52341  <---  Server: 10.0.0.20:1111
```

- 출발지 포트 52341: 클라이언트 운영체제가 새 연결을 만들 때 자동 할당한 임시 포트(Ephemeral Port) 예시. 필요하다면 애플리케이션이 직접 지정할 수도 있다.
- 목적지 포트 1111: 서버에서 요청을 받기 위해 설정한 서비스 포트.
- Vue 개발 서버의 8080 포트와 브라우저가 API를 호출하는 TCP 출발지 임시 포트는 다르다. 단, 개발 서버가 프록시 역할을 하면 백엔드 연결은 프록시가 새로 맺는다.

TCP 연결은 `출발지 IP + 출발지 PORT + 목적지 IP + 목적지 PORT` (4-Tuple)로 구분한다. 프로토콜까지 포함하면 5-Tuple이다. 따라서 동일한 서버 포트로 여러 연결이 동시에 들어올 수 있다.

## 대표 서비스 포트

| 서비스 | 일반적인 포트 |
| --- | ---: |
| HTTP | 80/TCP |
| HTTPS | 443/TCP (HTTP/3는 UDP) |
| FTP 제어 연결 | 21/TCP |
| SSH | 22/TCP |
| DNS | 53/UDP, 53/TCP |
| Oracle DB Listener | 1521/TCP |

서버 설정에 따라 기본 포트와 다르게 운영할 수 있다. FTP 데이터 연결은 별도의 포트를 사용한다.

## 우리 시스템의 서비스 포트 확인 방법

| 환경 | 확인 위치 |
| --- | --- |
| Jetty | 실행 설정, jetty.xml 등 |
| Tomcat | server.xml의 Connector |
| Spring Boot | server.port 설정 |
| WebLogic | 관리 콘솔의 Listen Port |
| 운영 서버 | `ss -lntp` (Linux), `netstat -ano` (Windows) |

L4, 웹서버, 프록시를 경유한다면 실제 WAS 포트가 아니라 호출자가 접근하는 VIP와 서비스 포트를 제공해야 한다.

## 면접 질문

**Q. 출발지 포트는 누가 설정하나요?**

A. 일반적인 클라이언트 TCP 연결에서는 운영체제가 임시 포트를 자동 할당합니다. 애플리케이션이 명시적으로 지정하는 것도 가능합니다.

**Q. 서버 포트 하나에 여러 연결이 가능한 이유는 무엇인가요?**

A. TCP는 출발지 IP·포트, 목적지 IP·포트의 조합으로 연결을 구분하기 때문입니다.
