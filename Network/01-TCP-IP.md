# TCP/IP와 4계층 (TCP/IP Model)

## 개념

TCP/IP는 인터넷 통신에 사용되는 프로토콜의 집합이다. TCP와 IP는 각각 독립된 프로토콜이며, TCP/IP에는 HTTP, DNS, UDP 등 여러 프로토콜이 포함된다.

프로토콜(Protocol)은 통신하는 양쪽이 데이터를 주고받고 해석하는 방법에 대해 정한 규칙이다.

| 계층 | 역할 | 대표 기술 | 데이터 단위 |
| --- | --- | --- | --- |
| 4. 응용 계층 (Application) | 어떤 규칙으로 요청하고 응답할 것인가? | HTTP, FTP, DNS, SSH | 메시지/데이터 |
| 3. 전송 계층 (Transport) | 어떤 프로세스에 어떤 방식으로 데이터를 전달할 것인가? | TCP, UDP | 세그먼트(TCP), 데이터그램(UDP) |
| 2. 인터넷 계층 (Internet) | 어느 목적지로 어떤 경로를 통해 패킷을 전달할 것인가? | IP, ICMP | 패킷 |
| 1. 네트워크 접근 계층 (Network Access) | 현재 네트워크 구간에서 다음 장비까지 어떻게 전달할 것인가? | Ethernet, Wi-Fi | 프레임 |

## 인터넷 계층과 네트워크 접근 계층의 차이

- 인터넷 계층: 최종 목적지 IP 주소를 기준으로 패킷을 전달한다.
- 네트워크 접근 계층: 랜선이나 Wi-Fi 등의 연결을 통해 다음 장비까지 데이터를 전달한다. Ethernet에서는 MAC 주소로 해당 구간의 전달 대상을 구분한다.
- 일반적인 라우팅 환경에서는 최종 목적지 IP가 유지되지만 Ethernet의 출발지·목적지 MAC 주소는 라우팅 구간마다 바뀔 수 있다. NAT가 적용되면 IP 주소도 변경될 수 있다.

## OSI 7계층과 비교

| TCP/IP 4계층 | OSI 7계층 (대략적 대응) |
| --- | --- |
| 응용 계층 | 7. 응용 / 6. 표현 / 5. 세션 |
| 전송 계층 | 4. 전송 |
| 인터넷 계층 | 3. 네트워크 |
| 네트워크 접근 계층 | 2. 데이터 링크 / 1. 물리 |

L2, L3, L4, L7 스위치의 숫자는 TCP/IP 4계층이 아니라 OSI 7계층을 기준으로 한다.

## 면접 질문

**Q. TCP/IP란 무엇인가요?**

A. 인터넷 통신에 사용되는 프로토콜의 집합입니다. 응용, 전송, 인터넷, 네트워크 접근 계층으로 구성되며 TCP와 IP는 각각 독립된 프로토콜입니다.

**Q. 인터넷 계층과 네트워크 접근 계층의 차이는 무엇인가요?**

A. 인터넷 계층은 최종 목적지 IP를 기준으로 패킷을 전달하고, 네트워크 접근 계층은 각 로컬 링크에서 다음 장비까지 프레임 등을 전달합니다.
