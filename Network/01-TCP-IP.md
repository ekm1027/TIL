# TCP/IP와 4계층

## 개념

TCP/IP는 인터넷 통신에 사용되는 프로토콜의 집합이다. TCP와 IP는 각각 개별 프로토콜이며 HTTP, DNS, UDP 등도 이 모델 안에서 동작한다. 프로토콜은 통신하는 양쪽이 데이터를 주고받고 해석하기 위해 정한 규칙이다.

| 계층 | 역할 | 대표 프로토콜·기술 | 데이터 단위 |
| --- | --- | --- | --- |
| 응용 | 어떤 규칙으로 데이터를 주고받을 것인가? | HTTP, FTP, DNS, SSH | 메시지 / 데이터 |
| 전송 | 어떤 프로그램에 어떤 방식으로 전달할 것인가? | TCP, UDP | Segment / Datagram |
| 인터넷 | 최종 목적지는 어디이며 다음 경로는 어디인가? | IP, ICMP | Packet |
| 네트워크 접근 | 다음 장비까지 실제로 어떻게 전달할 것인가? | Ethernet, Wi-Fi, ARP | Frame (물리 전송은 비트·신호) |

## 동작 원리

상위 계층은 하위 계층의 기능을 이용한다. 모든 계층의 프로토콜을 독립적으로 선택할 수 있는 것은 아니다. 예를 들어 HTTP/1.1은 TCP를 이용하고 HTTP/3는 UDP 기반 QUIC을 이용한다.

| TCP/IP | OSI 7계층과의 대략적인 대응 |
| --- | --- |
| 응용 | 7. 응용, 6. 표현, 5. 세션 |
| 전송 | 4. 전송 |
| 인터넷 | 3. 네트워크 |
| 네트워크 접근 | 2. 데이터 링크, 1. 물리 |

L2, L3, L4, L7의 숫자는 OSI 7계층 기준이다.

## 실무 예시

```javascript
axios.get("http://10.0.0.20:8080/customer?id=100");
```

- HTTP: 고객 정보 조회 요청을 표현한다.
- TCP: 데이터를 서버의 8080 포트로 신뢰성 있게 전달한다.
- IP: 목적지 IP를 기반으로 다음 경로를 결정한다.
- Ethernet: 해당 링크에서 다음 장비까지 프레임을 전달한다.

## 면접 질문

**Q. TCP/IP 4계층의 역할을 설명해 보세요.**

A. 응용 계층은 통신 규칙, 전송 계층은 프로세스 간 전송, 인터넷 계층은 IP 기반 패킷 전달, 네트워크 접근 계층은 구간별 실제 데이터 전송을 담당합니다.

**Q. TCP/IP와 TCP의 차이는?**

A. TCP/IP는 프로토콜 집합이며 TCP는 전송 계층의 개별 프로토콜입니다.
