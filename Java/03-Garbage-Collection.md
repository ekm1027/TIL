# Garbage Collection (GC)

## 개념
JVM에서 더 이상 접근할 수 없는 객체의 메모리를 자동으로 회수하는 기능이다.

## 코드 예시
```java
Object a = new Object();
Object b = a;
a = null; // b가 여전히 참조
b = null; // 다른 접근 경로가 없다면 GC 대상
```
GC 대상이 된다고 즉시 회수되는 것은 아니다.

## 동작 원리
- Mark: GC Root에서 접근 가능한 객체를 식별한다.
- Sweep: 접근 불가능한 객체의 공간을 회수한다.
- Compact: 필요에 따라 객체를 이동하여 빈 공간을 정리한다.

전형적인 세대별 GC에서는 Young Generation(Eden, Survivor)과 Old Generation으로 객체를 관리한다. Minor GC는 주로 Young 영역을 대상으로 한다. Major/Full GC의 범위 및 세부 동작은 수집기마다 다르다.

Stop The World는 GC 등의 작업을 위해 애플리케이션 스레드 실행이 일시 중단되는 현상이다. 모든 GC 작업이 중단 상태에서 이루어지는 것은 아니다.

## 실무 연관성
대용량 배치에서 데이터를 한 번에 객체로 적재하면 메모리 사용량과 GC 부담이 증가할 수 있다. 일정 단위로 나누어 처리하고 불필요한 참조를 유지하지 않는 방법을 고려한다.

## 면접 질문
Q. GC가 있어도 메모리 누수가 발생하는가?

A. 발생할 수 있다. 사용하지 않는 객체라도 접근 가능한 참조가 유지되면 GC가 회수하지 못할 수 있다.
