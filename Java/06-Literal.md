# 리터럴 (Literal)

## 개념
리터럴은 소스코드에 직접 표현한 값이다. 초기화는 변수에 최초로 값을 할당하는 행위이다.

## 코드 예시
```java
int a = 10;
int b = a;
a = 20;
String name = "Hello";
boolean active = true;
final int MAX = 100;
```
| 코드 | 설명 |
|---|---|
| int a = 10; | 리터럴로 초기화 |
| int b = a; | 변수의 값으로 초기화 |
| a = 20; | 리터럴로 재할당 |
| "Hello" | 문자열 리터럴 |
| true | 논리 리터럴 |
| MAX | 상수 변수 |

final 변수는 재할당할 수 없다. 참조형 final 변수의 경우 참조 대상 객체 자체의 불변성을 보장하지 않는다.

## 면접 질문
Q. 리터럴과 초기화는 같은 개념인가?

A. 아니다. 리터럴은 코드에 직접 표현한 값이고, 초기화는 변수에 최초로 값을 할당하는 행위이다. 리터럴은 재할당에도 사용할 수 있다.
